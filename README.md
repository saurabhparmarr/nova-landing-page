# NOVA — SaaS & AI Landing Page

A modern, responsive SaaS landing page concept for **NOVA**, a fictional AI-powered productivity platform designed to help teams automate workflows, analyze performance, and collaborate more efficiently.

Built as a Front-End Development Intern assignment using **React, Vite, Tailwind CSS, and Lucide React**.

## 🚀 Live Demo

**Live URL:** https://nova-landing-page-virid.vercel.app

## 📌 Project Overview

NOVA is a fictional SaaS/AI company that provides intelligent tools for modern teams.

The landing page focuses on:

* Modern SaaS-style visual design
* Responsive layouts across devices
* Clear product positioning
* Interactive UI components
* Accessible semantic HTML
* Reusable React components
* Smooth navigation and user interactions

## 💻 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/saurabhparmarr/nova-landing-page.git
```

Navigate to the project:

```bash
cd nova-landing-page
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

## 📦 Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

Run ESLint:

```bash
npm run lint
```

## 📱 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile devices

Responsive Tailwind CSS utilities are used throughout the application to maintain consistent layouts and prevent horizontal overflow.

## ♿ Accessibility

Accessibility considerations include:

* Semantic HTML elements
* Accessible button labels
* Keyboard focus states
* ARIA attributes for interactive components
* Descriptive navigation links
* Proper heading hierarchy
* Form labels for inputs

## 🎨 Design Approach

The design follows a clean, modern SaaS aesthetic using:

* Minimal color palette
* Strong typography hierarchy
* Rounded cards and containers
* Subtle shadows
* Smooth hover transitions
* Consistent spacing
* Clear call-to-action elements

The goal was to create a professional product landing page rather than a basic tutorial-style website.
